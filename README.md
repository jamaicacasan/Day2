My Website Output

My Website is a simple website created using HTML. It consists of three web pages: Home, Lists, and Forms. The project demonstrates basic HTML elements, page navigation, different types of lists, and form controls.

The project contains three HTML files and one README file.
My-Website/
├── index.html
├── lists.html
├── forms.html
└── README.md

This project aims to demonstrate an understanding of:
Basic HTML document structure.
Headings, paragraphs, and horizontal rules.
Navigation using anchor tags.
Ordered, unordered, and description lists.
HTML form elements and input types.
Basic website organization using multiple HTML files.
